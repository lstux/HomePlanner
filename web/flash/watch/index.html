Installer la montre

Il faut : un ordinateur avec Chrome ou Edge, une LilyGO T-Watch 2020 et un câble USB de données.

Avant la première fois, sauvegarde la montre (cette page ne sait pas le faire) :

pip install esptool
python -m esptool --port <PORT> --baud 921600 read_flash 0 0x1000000 sauvegarde-twatch.bin

  1. Branche la montre, allume-la et ferme tout moniteur série.
  2. Choisis la version de ta montre (celle que tu utilises pour Slovingo).
  3. Clique sur le bouton, puis choisis le port USB.
  4. Laisse « Erase device » décochée : sinon réglages et leçons de la montre sont effacés.

Le firmware n'est pas publié ici pour le moment.

Ce navigateur ne sait pas flasher : utilise Chrome ou Edge sur ordinateur. La page doit être ouverte en HTTPS.
