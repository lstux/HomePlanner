Installer la centrale

Il faut : un ordinateur avec Chrome ou Edge, une carte Waveshare ESP32-C6-LCD-1.47, un câble USB-C de données, et une carte microSD (FAT32) insérée.

  1. Branche la carte à l'ordinateur et ferme tout moniteur série.
  2. Clique sur le bouton, puis choisis le port USB de la carte.
  3. Mise à jour : laisse la case « Erase device » décochée pour garder Wi-Fi et code d'appairage.
  4. Attends la fin, puis regarde l'écran de la carte.

Le firmware n'est pas publié ici : cette page ne fonctionne que sur le site déployé par GitHub Pages.

Ce navigateur ne sait pas flasher : utilise Chrome ou Edge sur ordinateur. La page doit être ouverte en HTTPS.
